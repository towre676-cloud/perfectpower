# Emitted example instances

These seven files are emitted proof sources, not newly accepted proofs from this run. The hidden-needle file independently invokes native divisor solving on the small centered polynomial and states the exact coordinate transport. The six constraint files invoke the existing complete source theorems and prove the finite residual equivalences if compiled successfully. Their emitting Python code and each source query are committed alongside them.

From a configured Lean 4.20.0 checkout with the relevant repository dependencies built, compile an instance with `lake env lean receipts/showcase/lean/HiddenNeedle.lean` or the corresponding constraint filename. No admitted theorem or bypass is included. The validation packet retains `EMITTED_NOT_COMPILED_IN_THIS_RUN` until an actual instance build succeeds.
