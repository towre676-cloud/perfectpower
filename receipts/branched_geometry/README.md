# Exact branched geometry

See [the mathematical monograph](../../docs/BRANCHED_GEOMETRY_MONOGRAPH.md). quartic_topology.json links 12,320 profiles to the existing source hash. connections.json contains all twelve exact monodromy-pattern matrices. examples.json contains ten examples. cell_models.json retains triangles, edges, faces, boundary matrices, finite Hodge operators and trivalent dual data.

GeometryCells.lean checks the six model chain identities and six face charges. IntegerLiftPackets.lean checks coordinate transformations for five actual integer Smith packets. Generic proofs are in PerfectPower/BranchedGeometry.lean and PerfectPower/IntegerLiftRecovery.lean. validation.json records actual completed checks. No intrinsic Voronoi metric, analytic period computation or new arbitrary integer-height bound is claimed.
