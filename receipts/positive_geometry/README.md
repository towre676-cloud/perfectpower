# Reproducible positive-geometry corpus

Run PYTHONPATH=python python python/build_positive_geometry.py from the repository root to regenerate this directory's mathematical JSON. summary.json gives actual census sizes. manifest.json binds the generated files. validation.json and the test logs record separate execution checks.

The collision atlas records normalized collision polynomials, not arbitrary stable limits. Associahedra are real configuration chambers. Root-channel graphs retain cyclic sheet transport. Their basis polytopes are representable-matroid Newton polytopes, without an asserted general amplituhedron identification. Descartes hits have exclusive finite scan bounds. Period corrections consume supplied exact data, without generating analytic periods.

The new Python results are not Lean theorems. The separate session can use lean_handoff.json and docs/POSITIVE_GEOMETRY_LEAN_HANDOFF.md to formalize them. The preceding branched-geometry module has its own compiled Lean statements, which are neither removed nor automatically extended here.
