How the exact answer is calculated

This puzzle uses twelve consecutive original Petersen projects, original scores and all five original cost columns. Reproducible puzzle budgets are derived from the seed and differ from the full published problem. PerfectPower’s browser integer factor counter counts the complete feasible population; exhaustive finite optimization finds every best choice. There are 4,096 possible subsets, including the empty subset when no project is required. This browser challenge is tested computation, not a claim that its JavaScript engine is Lean-proved.

Local progress stays in this browser. Share links contain the puzzle seed, mode and selected project bits; no personal data is included. The geometric artwork above is illustrative.
