# The room of possibilities

Open **PerfectPower-Room-of-Possibilities.html** directly in a modern WebGL 2 browser. It contains its renderer, exhibit code and exported population data and needs no network. The three-dimensional museum explains search, reusable constraint maps, and the original integer family `2x² = 3y³`. It includes requirement comparisons, saved device-local scenes, a twelve-component design workbench and an exact family notebook. The machine workshop's 288 designs use invented integer scores rather than physical predictions.

The new **Compare exact populations** notebook displays actual `PopulationComparison` exports for `T=10^40` and `T=8`. It shows intersections, differences, the bounded complement, union and symmetric difference, with stable original-object identifiers and all nine addresses for selected points. Counts and addresses remain decimal strings. Visit a point in the mathematical hall or download the evidence. This notebook is independent of the fictional workshop's browser-only A/B snapshots.

For live Python replay, install the package from the repository checkout and run `python -m perfectpower service --database pp.sqlite --http-port 8080`. Open `http://127.0.0.1:8080/atlas`. The replay button submits the exact saved JSON definition to the local engine and displays its raw response. Opening the file offline disables this action. A wheel installed without the repository's web files does not include the `/atlas` document.

To rebuild, install Node.js and Python, run `npm ci` in this directory, then run `python ingest.py --repo ../..` and `python build.py`. The lockfile pins Three.js and esbuild. `make room-of-possibilities` performs ingestion and bundling once dependencies are installed. The finished HTML is checked into the repository, so visitors need no build tools. Ingestion records the checkout base, whether files were modified, and hashes of the executed source files. The [population algebra monograph](../../docs/POPULATION_ALGEBRA_MONOGRAPH.md) explains the backend contracts and formal boundary.

Browser verification uses Playwright and Chromium. Install Playwright for local checks and its Chromium runtime, then run `node check-browser.cjs`, `node check-detail.cjs` and `node check-comparison.cjs`. Optional environment variables `BROWSER_EXECUTABLE_PATH` and `BROWSER_LIBRARY_PATH` select a local browser and native libraries. The three receipts pin the tested HTML hash. The comparison check tests both offline mode and an actual local Python server; it requires the package to be importable from this checkout. Screenshots include desktop and mobile comparison views.
