# Dresden Codex Observatory

A React and Three.js research explorer built from PerfectPower's source-driven Dresden module. Six views cover exact calendar arithmetic, all 69 published eclipse stations, all 260 Venus labels, all 405 supplied lunar interval distributions, restart-order comparisons and primary sources. Three.js WebGPURenderer prefers WebGPU and uses its built-in WebGL 2 fallback. Integer arithmetic and population counts use BigInt; the rendered scene is presentation geometry rather than a physical orbit or an ancient device.

Install with the checked-in pnpm lockfile, then run `pnpm dev` or `pnpm build`. The normal site uses the supplied Vinext/Cloudflare starter. Run `pnpm exec vite build --config vite.standalone.config.ts` followed by `node scripts/pack-standalone.mjs` to produce a self-contained HTML companion in `outputs/`. It embeds React, Three.js, numerical datasets, styles, the attributed source figures, facsimile images and monograph. Open the HTML in a modern browser; GPU support still depends on the browser and device. No CDN or network is required for the embedded experience. External source links remain external.

`node --experimental-strip-types tests/math-parity.mjs` compares the browser calendar, Long Count and all five overlap policies with fixtures produced by the Python engine. It also exhaustively checks small noncoprime CRT cases and exercises very large exact populations and malformed inputs. TypeScript and the production builds pass. Full browser/GPU execution and optional WebMCP tool validation were unavailable in the build environment; GPU initialization errors retain the accessible two-dimensional calculations and source views.

The original research input is PerfectPower local commit 109d8a3. The JSON datasets preserve publication coordinates and source provenance. Numerical disagreement does not determine a manuscript glyph. Lunar appearances are the authors' modeled outputs, not ancient observations; no new ephemeris or historical visibility calculation is supplied. The sources view and PDF monograph give the detailed mathematical scope. Justeson and Lowry (2025), DOI 10.1126/sciadv.adt9039, supply the CC BY 4.0 article figure copies and derived numerical records. The historical Förstemann facsimile images are attributed to FAMSI's original PDF packets. Venus number labels come from Juárez Nájera and Castellanos (2020), DOI 10.19130/iifl.ecm.2020.56.2.0004. Aldana's 2016 correction interpretation is attributed and linked; its full article is not redistributed.

The second research layer adds editable simultaneous calendar constraints with rank selection, complete station/reading ledgers, exact rational Venus envelopes, recomputation over arbitrary contiguous lunar windows, exact empirical moments and total variation, rank inversion of overlapping predictions, rational restart sensitivity with every tie, and a searchable/exportable source transformation ledger. `node --experimental-strip-types tests/deep-parity.mjs` compares all new arithmetic with the Python receipts; `node tests/render-views.mjs` checks all six React views through server rendering. JSON exports encode BigInt values as decimal strings. Raw appearances and their original cached JDN strings are included. A central empirical percentile interval is descriptive rather than a confidence interval.
