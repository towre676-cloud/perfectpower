# Exact population handoff

This release adds python/perfectpower/populations.py and population_cli.py. It integrates the population command into the existing console. Read docs/POPULATION_MONOGRAPH.md for the mathematics and docs/DIRECT_USE_BUILD_ROADMAP.md for all proposed application fronts.

Run PYTHONPATH=python python -m unittest discover -s python/tests -p test_populations.py -v, then PYTHONPATH=python python python/develop_populations.py. The generated receipt directory includes 256 signed curve records, 128 compatible layouts, 768 related tasks and 512 sourced Bober recurrence-unit index records.

The first product surface is ExactPopulation: finite domain or curve specifications; count; select; rank; locate; page; next; restrict; optimize; sample; partition; export. Curve ordering is chart-major for explicit generators, lexicographic for complete finite point lists. Domain configurations retain parameter identity. Rank sharding is contiguous and balanced. Sampling without replacement uses sparse Fisher-Yates.

This is a standard-library application layer over existing complete arithmetic. No new Lean theorem is claimed. The remaining high-return work is application integration, arbitrary projected-image multiplicity handling, service persistence and backend expansion. Preserve concurrent research changes and push additions onto the current repository branch without force updates.
