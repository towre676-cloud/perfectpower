Read `docs/DRESDEN_NUMERICAL_MONOGRAPH.md`, `research/dresden/NOTICE.md` and `research/dresden/sources.json`. Run `make dresden-test` and `make dresden`. Execute JSON with `PYTHONPATH=python python -m perfectpower.dresden research/dresden/venus_request.json` or `research/dresden/restart_request.json`. Core sources are `python/perfectpower/dresden.py` and `python/perfectpower/dresden_eclipse.py`; worked outputs are `receipts/dresden/corpus.json` and `receipts/dresden/lunar_census.json`.

This release independently recomputes selected Venus correction arithmetic, audits all 260 published Venus numbers and all 69 published eclipse stations, and recomputes every 1–405 month interval from 8,052 supplied modeled lunar appearances. It executes exact distinct overlapping restart populations and global bounded minimax ordering under declared rounded mean offsets. It supplies no complete independent glyph transcription, new astronomical ephemeris, historical visibility validation or new Lean proof. Preserve the surviving 11,959-day table separately from the two proposed 11,960-day alternatives. Keep source discrepancies, original workbook cells and synthetic examples explicitly labelled.

The arithmetic modules use the Python standard library and existing PerfectPower engines. Optional acquisition, XLSX ingestion and PDF rendering scripts are in `scripts/`. Original S1/S2 workbooks remain unchanged. `scripts/ingest_dresden_lunar.py` parses numeric XML caches, retains their decimal strings and computes integer days as floor(JDN). Full regression logs precede the last source-data additions; the final focused log covers all 24 Dresden tests. Never add overlapping interpretation counts as a distinct-date population.

The interactive React/Three.js source is `web/dresden-observatory`; follow its README for the hosted build and self-contained HTML build. Browser BigInt arithmetic matches the Python fixtures in the web math-parity receipt. Browser/GPU execution remains untested in this environment.

Run `make dresden-deep` for the complete deep-research receipt.
