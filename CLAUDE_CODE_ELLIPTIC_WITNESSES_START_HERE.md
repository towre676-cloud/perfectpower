# Elliptic witnesses: start here

Read docs/ELLIPTIC_WITNESSES_MONOGRAPH.md and receipts/elliptic_witnesses/summary.json. The public elliptic_curve catalogue kind adds exact generalized Weierstrass arithmetic, supported rational model transport, rational two-isogenies, complete rational halving fibres and witness-span rank lower bounds. Preserve all preceding polynomial, curve and flavor work.

The implementation is python/perfectpower/elliptic_arithmetic.py and elliptic_certificates.py. Discovery-free checking is in elliptic_certificate_verifier.py; it uses separate local characters and separate binary elimination, sharing rational/group arithmetic and the signed-remainder Sturm checker. The new schemas are pp-rational-halves/1, pp-rational-roots/1 and pp-elliptic-independence/2. Independence replay rejects the unsupported legacy /1 schema instead of silently upgrading its evidence.

Run make elliptic-witnesses, then make test. Regenerate the corpus into a new directory with PYTHONPATH=python python python/develop_elliptic_witnesses.py --output /tmp/elliptic-replay and compare it byte for byte with receipts/elliptic_witnesses. Replay service_requests.jsonl through python -m perfectpower service using a fresh SQLite database; stdout must match service_responses.jsonl. The script itself closes and reopens its catalogue after every request.

The rank-two example is y^2=x^3-4*x+1 with witnesses (0,1) and (2,1). Their doubles exercise two recorded halving changes. The source sextic y^2=x^6-4*x^2+1 lifts only the first quotient witness rationally; keep the square condition u=x^2. Four complete rational [2] fibres cover infinity, an empty fibre, a unique half and four halves. Scientific packets contain no timings. Validation results are recorded separately in docs/ELLIPTIC_WITNESSES_VALIDATION.md.

Producer limits: 64 witnesses, prime bound at most 2000, at most 64 halving replacements, root-node budget at most 100000, model coefficients at most 8192 bits and point coordinates at most 12000 bits. A exhausted root budget raises an error, never a partial complete answer. Checker work is independently bounded. Do not call the p-adic discovery failure proof of an empty fibre; the complete quartic root certificate supplies that guarantee.
