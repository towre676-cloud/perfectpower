# Five/seven subgroup and saturation handoff

This push connects the existing complete rational five/seven fibres to subgroup preimages and repeated bounded saturation. It adds explicit row-Hermite/Smith coefficient lattice forms, exact original-generator containment, separate actual free subgroup index certificates and a finite-prime polynomial-root obstruction that makes the mixed-generator examples practical. The source branch is claude/laughing-lamport-qqzdo9. Existing arithmetic-chart, wall and flavor work is preserved.

Run `make check-elliptic-prime-subgroups`. It rebuilds twenty packets in `receipts/elliptic_prime_subgroups`, eighty independent SymPy normal-form cases, 28,656 residue coordinates, forty rational division-coordinate checks and the full elliptic unittest family. Fourteen focused tests are in `python/tests/test_elliptic_prime_subgroups.py`; exact totals are in `validation.json`. This is exact computational/paper-proof work; no fresh Lean execution is claimed.

`python/perfectpower/elliptic_subgroups.py` accepts primes 2,3,5,7 and retains every projective coefficient line. Its concurrent version-two schema and historical version-one replay are preserved. `elliptic_subgroup_verifier.py` dispatches five/seven fibres to independent original-model recurrence replay. `elliptic_saturation_verifier.py` accepts the enlarged prime set; the existing saturation search and positive membership witnesses remain intact. New methods in `elliptic_arithmetic.py` are subgroup_presentation and saturation_presentation, with separate normal-form schemas. The wrapper defaults to primes [5,7]; the historical bounded_saturation default remains [2,3].

`elliptic_lattice_presentation.py` constructs H,U,V with UHV=diag(1 repeated d,p repeated r−d), the source-containment matrix and optional actual-index packets. `elliptic_lattice_verifier.py` checks determinants, unimodularity, Hermite inequalities, finite relation inclusion, point equations and independently certified free coordinates. The coefficient-lattice index p^(r−d) and the relation cardinality p^d must never be presented as actual subgroup indices for dependent or torsion inputs. Actual indices require certified witness independence, exact coordinate matrices and a trivial rational p-kernel.

The JSON dispatcher preserves every old operation and adds verify_elliptic_subgroup_presentation, verify_elliptic_saturation_presentation, elliptic_subgroup_index and verify_elliptic_subgroup_index. New curve methods work through persisted Catalogue objects and cold reload. Complete prime fibre packets additionally accept the local_root_obstruction method with exactly one extra local_obstruction field; historical field sets remain supported. The obstruction uses monicity and complete finite root/square tests, not rational-root discovery or an assumed finite-reduction group law. Failed obstruction search remains inconclusive.

The flagship curve y²=x³−4x+1 has P=(0,1), Q=(2,1). At p=5 and p=7, sources P+Q,(p−1)P−Q are individually indivisible but their sum is pP. Every line is retained; the exact relation basis is (1,1); actual index p is certified. On y²+y=x³−x, the subgroup generated by 35(0,0) reaches joint five/seven closure via stages 5,5,7,5,7 with actual indices 5,1,7,1,1. Separate packets test duplicate generators, full five/seven torsion kernels, one-step limits and inconclusive bounded membership.
