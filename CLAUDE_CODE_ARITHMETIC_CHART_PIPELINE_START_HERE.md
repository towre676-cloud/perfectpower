# Arithmetic chart pipeline

This release connects rational polynomial power equations, denominator residue charts, complete local Hensel/CRT covers, content-normalized singular blowups, bounded source coordinates and unordered weighted determinant relations. The core source modules are `integer_valued_power_charts.py`, `branching_residue_patch.py` and `unordered_weighted_determinant.py`. The three corresponding Lean modules prove equation transport, affine chart composition and the general order-free weighted determinant identity.

Run `make arithmetic-chart-check` with Lean 4.20.0 on PATH. The target builds the generic modules, checks 123 focused and neighboring tests, reproduces ten native programs and their receipts, runs independent source censuses and checks every printed theorem dependency. Python modules use exact integers and rational coefficients; the renderer is optional and imports reportlab/matplotlib separately.

The main JSONL entry point is `integer_power_charts` with `coefficients`, `exponent`, `bounds`, optional integer `offset`, and optional `factors` as prime/exponent pairs. `integer_power_chart_scan` returns complete bounded source solutions; `integer_power_chart_population`, `integer_power_chart_select` and `integer_power_chart_rank` query the modular candidate population. `branch_integer_power_charts` and `scan_branch_integer_power_charts` intersect exact normalized blowup leaves with the same CRT constraints. `branching_residue_patch` applies blowups directly to a bivariate integer polynomial. `chart_weighted_determinant` derives local monomial weights from actual source-chart points and returns an exact auxiliary relation when the matrix is singular. Each family has replay and native-certificate operations.

Do not mistake a modular candidate for an exact source zero. Do not mistake a declared box for a global height bound. Work exhaustion raises an error and never returns a partial cover. The generic Lean chart semantics and the source-bound certificates are kernel proofs; a universal refinement theorem for the Python recursive interpreter and factor traversal remains open, as does a general Lean identification of the order-free alternating coefficient with canonically enumerated minor products. The emitted finite minor certificates do prove the literal products in every retained case.

The monograph is `docs/ARITHMETIC_CHART_PIPELINE_MONOGRAPH.md`, with a matching PDF. `receipts/arithmetic_chart_pipeline/summary.json` gives the worked cases and `crosscheck.json` gives independent census totals.
