# Complete rational tripling and composite division handoff

The integrated implementation solves complete rational [3] fibres and [n] fibres for n≤36 supported by primes 2 and 3. It preserves the incoming consolidated branch at 2a971d0, including native population proofs and the separate flavor advances. The arithmetic is in python/perfectpower/elliptic_division.py; exact curve methods and public dispatch are wired in elliptic_arithmetic.py and query_service.py. Discovery-free replay lives in elliptic_division_verifier.py, with an independently expanded tripling numerator.

Run make elliptic-composed-division and make test. Read docs/ELLIPTIC_COMPOSED_DIVISION_MONOGRAPH.md and the validation document before changing certificate schemas. The scientific corpus contains nineteen packets, including rational nine-torsion in generalized coordinates, finite three-point cosets, empty fibres and thirty-sixth recovery. Service requests close and reopen the persisted catalogue between calls. The complete package contains all tracked repository content; extract every archive part into the same directory.

Every stage must retain exactly one complete prime fibre per ordered target. Work is charged against one request-wide root-node budget. A missing anchor requires an exhaustive finite-target root certificate before claiming emptiness. Do not drop square-lift restrictions or replace a full signed point equation with an x-coordinate condition. A bounded p-adic discovery failure is not an obstruction. Prime factors outside {2,3}, scalars outside 1..36 and exhausted budgets fail explicitly.

The mathematical Lean foundations already exist in PerfectPower/EllipticDivision.lean, EllipticPointDivision.lean and NativeRationalRoots.lean. This release adds Python execution and replay, not new Lean verification. Useful next work is formal tripling algebra and point-law refinement, a typed staged-fibre interpreter, or lattice saturation over all residue combinations. Dividing individual witness points is insufficient for lattice saturation or a complete rank statement. No global integral-point bound is supplied.
