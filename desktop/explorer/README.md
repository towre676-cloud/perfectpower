# PerfectPower Explorer

PerfectPower Explorer is an offline Windows application backed by the complete repository. Its landing scene renders the projected square-root sheets of w²=z³−2. The equation laboratory runs exact integer-point searches through PerfectPower's existing arithmetic, then plots the real curve and the retained points. The repository view opens every indexed file, renders Markdown, inspects structured JSON and displays retained visual applications. Workbench forms are generated from the actual argparse definitions, including the separate BLAST command interface.

The Windows package includes Electron, an official embedded CPython runtime, the declared numerical dependencies and precompiled source-bound planner and CNF-counter DLLs. The installer installs the portable folder to the Desktop, creates a shortcut and opens the application. Existing version folders are preserved. No separate Python installation or terminal is required.

Developer launch uses `python desktop/explorer/server.py`. Install interface dependencies with `cd desktop/explorer && npm ci`, then run `npm run build`. Generate the catalogue from the checkout with `python desktop/explorer/catalog.py`. Native binaries carry source and binary SHA-256 sidecars. The loader rejects a stale or damaged shipped binary; ordinary source checkouts retain their existing compiler route.

Run `python desktop/explorer/check-engines.py` for the new engine routes. Run `node desktop/explorer/check-browser.cjs` with `BROWSER_EXECUTABLE_PATH` pointing to a Chromium executable for the interface checks and screenshots. The Windows packaging script accepts official Electron and CPython ZIPs, a directory of Windows wheels, an output directory and a MinGW compiler path. Run `python desktop/explorer/package_windows.py --help` for those arguments.

This release preserves the upstream command contracts. Commands requiring Lean, PARI, Sage, NCBI BLAST+ or other external tools still require those tools. Source inclusion is not a fresh proof compilation. The complete repository content is included; this release does not supply a bespoke interactive visualization for every historical Python API. Large output previews are shortened, and the saved export retains the complete engine output.

See ../../docs/PERFECTPOWER_EXPLORER_MONOGRAPH.md for the mathematical display, execution architecture, retained checks and Windows testing limitations. See THIRD_PARTY_NOTICES.md for asset and dependency sources.
