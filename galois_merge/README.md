# Galois × Forge: exact transport and completeness architecture

Start with CLAUDE_CODE_START_HERE.md and docs/MATHEMATICAL_MERGE.md. This is a compact additive handoff, not a replacement for PerfectPower or the full Forge archive. It preserves selected original Forge source/data and contributes executable integer transport, absolute-bound propagation, exact obligation interning, sequence offset checks and adapters for the actual repository data.

Executed: 8 Python tests, exact verification of 5 original Forge rational programs, recomputed task-signature geometry, directional profiles of 4 original Forge programs at 5 independent primes, 1200 exact derived-family transport experiments, and 1000 finite modular checks. Degree-eight directional calls reproduce 82/81 and degree-nine calls reproduce 114/92. This is genuine work on the uploaded source archive. Derived cubic experiments are labeled and do not pretend to be the absent 316-branch ledger.

The full earlier OEIS ZIP and current PerfectPower repository were unavailable. corpus_adapter.py reads the real .seq directory or ZIP in Claude's environment without extracting the whole corpus. No new OEIS definitions were acquired or promoted here. The parser test uses a synthetic fixture and is labeled as such.

Run `python3 -m unittest discover -s tests -v`, `python3 run_experiments.py`, and `python3 reproduce_directional.py`. The arithmetic tools use the standard library; actual Forge checks require NumPy. Windows can use `py -3`. Read adapters' module docstrings for input schemas. requirements.txt records the dependency, not a forced change to the existing repo environment.

Lean drafts were not compiled. No new Mordell completeness theorem is claimed. The mathematical merge specifies how to use exact transport, small task interfaces, shared bound infrastructure and cost accounting for the 23 remaining negative-k curves, D=72, positive k and sequence shifts. It expressly distinguishes field reuse from integral equivalence and local evidence from global completeness.
