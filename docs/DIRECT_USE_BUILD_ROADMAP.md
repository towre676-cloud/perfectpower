# Direct-use build roadmap

The open-content release removes the archive cap and implements the executable extensions below. Each row states the direct output a user can create, how it compares with a conventional workflow, evidence, and the precise remaining work. A software closure applies only to its declared model. The full historical research notes are retained in `receipts/open_content/open_source_inventory.json`; their keyword matches are review pointers, not a list of newly proved theorems.

| Application and beneficiary | Direct new output and conventional comparison | Delivered implementation and evidence | Remaining scope, stated precisely |
|---|---|---|---|
| Exact configuration generator — engineers building constrained products | Create an addressable configuration universe with original parameters and derived dimensions; count and sample it at capacities impossible to materialize. A conventional list generator needs one row per configuration. | `ExactPopulation`, persisted definitions, rank/select/locate, constraints, exports, shards; eight object kinds through the same catalogue. The current square-value source has 2×10^50+1 identities. | Real application schemas and objectives must be supplied. Supported predicates and complete curve backends define the boundary; arbitrary configuration languages are not implemented. |
| Square/cubic layouts — compute and storage authors | Generate integer tile dimensions row=n³ and column=n² with row²=column³ and exact capacity filters. This creates a coupled design family ready for execution, instead of independent dimension sweeps followed by rejection. | Eight compatible configurations under a 262,144-byte logical output-tile budget; real compiled 96×96 and 192×192 products, every full output checked against independent Python dot products. | Equality is an application constraint, not a performance theorem. Hardware, storage and simulation users need their own objectives, layouts and workload measurements. |
| Compiler autotuning — kernel developers | Execute the entire bounded compatible candidate family and choose its measured best median. Standard unconstrained autotuning can search other tile families; this tool adds exact coupled candidates and reproducible trial provenance. | C99 kernels compiled together with `-O3`; seven measured rounds after two warmups; candidate, conventional dot-product and cache-friendly untiled controls interleaved. Source hash, flags, CPU, every trial and output hash recorded. | Performance applies to the recorded host and two integer workloads. Results include the stronger untiled control; no BLAS comparison or universal speedup is claimed. |
| Mathematical data — dataset builders | Sample uniformly over distinct projected values, while retaining an owner and exact multiplicity back to source identities. Uniform source sampling conventionally overweights values with several preimages. | `ProjectedPopulation` for degree 0, 1 and 2 fields. Quadratic collision identity determines canonical owners without enumeration; 10^50+1 distinct squares, multiplicities, samples and ranks. Asymmetric/modular domains independently checked. | Higher-degree image multiplicities and custom distributions need new algorithms. Ranks follow canonical source owners, not sorted numeric values. |
| Mathematical AI tasks — benchmark authors | Publish tasks from entire held-out mathematical families and run a baseline using only public prompts. This tests source-family separation beyond a random point split. | Eight exponent families; 256 train, 128 validation, 128 test tasks; aliases crossing partitions rejected. Exact public-prompt solver answers all 128 test tasks correctly, with measured query ledger and compile reuse. | This is an exact-solver baseline, not measured LLM performance. Blind agent evaluation must withhold the private answer file; declared family labels need semantic review to prevent equivalent but differently encoded families leaking. |
| Integer inverse design — calibration authors | Return all closest bounded integer actuator settings under exact observations, linear inequalities and a positive definite metric. Conventional continuous optimization must add a discrete search to supply this output. | `InverseDesign.solve_box`; exact interval feasibility pruning and Schur-complement energy bounds; nonnegative actuator example plus 25 randomized models independently exhausted. Infeasibility and all optimal ties are retained. | Completeness is within the supplied finite box and work budget. Real observations, tolerances, nonlinear constraints and unbounded mixed-integer inequalities are separate tasks. |
| Shared sequence execution — recurrence authors | Compile named outputs onto common exact state machines, then execute huge indices modulo a chosen modulus. Conventional independent recurrence loops repeat the transition work for each output. | Reviewed source definitions and offsets for Fibonacci, Lucas starting at 2, Lucas starting at 1, and Pell; every stored term checked; two shared machine definitions and source hashes. | Definitions are premises; prefix agreement does not establish an unknown sequence law. Broader sequence classes require their own certificates. |
| Distinguishing experiments — diagnostics researchers | Find the globally cheapest separating operator word/readout under positive operator costs. A stored certificate witness supplies separation but can be expensive. | Exact Dijkstra search on compressed observable differences, finite incumbent and dominance pruning. Demonstration improves witness cost 100 to global cost 2; multi-operator search compared with independent short-word enumeration. | Positive operator costs, nonnegative readout costs and state/bit budgets are required. One cheapest experiment is returned; noisy observations and adaptive statistical experiment design are not modeled. |
| Executable nonlinear sequence laws — combinatorial and modular-arithmetic authors | Reuse stripped factorial units across multiple nonlinear factorial-ratio sequences and obtain residues at index 10^100, including indices with singular recurrence denominators. A direct recurrence loop cannot reach that index. | New `FactorialLibrary`; all 52 sourced Bober families, polynomial-coefficient recurrence and Landau certificates, 624 literal factorial checks, huge-index residues modulo 7³ and 17². Shared slope computations are recorded. | Supports supplied factorial-ratio definitions, not arbitrary nonlinear recurrences. Rational terms with negative p-adic valuation return no residue; global integrality has a separate Landau certificate. |
| Combinatorial size design — combinatorial engineers | Select complete square-triangular Pell sizes under enormous bounds, retaining the root and application dimensions. A bounded trial loop must examine candidate sizes individually. | Existing `CombinatorialDesign` integrated alongside all new kinds; service example retains complete sizes below 10^100 and Gamma analysis. Nonlinear factorial library extends direct modular uses. | New effective Gamma power-value analyses and other combinatorial constraints remain mathematical work; residue execution alone does not solve perfect-power questions. |
| Embedded service — application developers | Use persistent exact objects from a local interactive HTTP console or JSONL process. The service adds reusable mathematical definitions and isolated request errors to ordinary transport. | `python -m perfectpower service --database /tmp/pp.sqlite --http-port 8080`; actual HTTP registration/query/error/continuation tests; all eight kinds in a portable request transcript. Client preserves full response digits. | Local single-worker loopback deployment. Public hosting, authentication, concurrent database access and a domain-specific GUI require an explicit deployment design. |
| Compact database — pipeline developers | Join huge parameter populations symbolically while preserving every source pair, then count/rank/sample the result. A conventional materialized equality join requires reading all source rows. | Supported `f(x)=g(y)` joins compiled as complete original-coordinate curves. Self-join of squares over ±10^50 has 4×10^50+1 pairs without materialization; zero and signed branches counted correctly. Existing small bounded joins remain. | Symbolic joins require supported complete curve backends; generic multicolumn, constant-plane and arbitrary relational joins are unsupported. Distinct projection and pair multiplicity have deliberately different identities. |
| Graph ensembles — stochastic gain-network researchers | Produce exact conditional random bases for cyclotomic orders 2 through 64. Floating probability evaluation conventionally approximates the distribution; rational-only sampling cannot express these cases. | Lazy random dyadic comparison against rational enclosures of algebraic probabilities; all 63 orders, 504 samples, every decision replayed. Include/exclude conditioning, zero-mass failures and immutable reweights retained. | These are specified gain-graph basis measures, not a generic network-performance model. Analytic enclosure code is Python, not Lean-certified; a bit-budget failure yields no draw. No benchmarked distribution-speed advantage is claimed. |
| Geometry workbench — geometry researchers | Transport exact points and compatible density bounds between branch/infinity charts and a finite chart. Separate panels conventionally leave the identification and metric Jacobian to the user. | Rational complex transition maps, exact polynomial metric identities, Bernstein-certified full source-panel containment, local transport and interactive exact readouts. Odd/even infinity identities tested through degree nine, genus four. | Two overlap types, not a complete atlas. Global shortest paths, topology-wide coverage, normalized analytic Bergman periods and smooth arbitrary-genus Voronoi boundaries remain open. |
| Arithmetic research instrument — arithmetic researchers | Compose supported domains, projected values, joins, sequences, constraints and graph/geometry packets into persistent experiments. Conventional notebooks provide orchestration but need these completeness and identity contracts supplied separately. | Portable definitions, source inventory, method allowlists, receipts and full uncapped source archive; no source history or existing theorem evidence removed. | General Sturm and compiler kernel proofs, broader Baker/number-ring backends, Matveev premise discharge and larger descent slabs remain research/proof work. Full historical notes are preserved and linked. |
| Symmetry/flavor — mathematical physics researchers | Compute the exact coefficient subspace that preserves the nominated phase and exhibit the response to a permitted deformation. This turns a proposed scalar value into a reproducible test of model identifiability. | Degree-12 CP-even harmonic space: 13 coefficients, rank-eight stationarity constraints, five-dimensional kernel; exact linear response for two lock choices; golden closure changes under εx; full allowed-operator audit and interaction obligations. | The physical golden coefficient and 66° phase are not derived. A noncentral charge-compatible interaction, three-light-family mechanism, correlated up/down breaking, canonical normalization and protected vacuum selection are still required. Hall, Pillai and abc also remain open. |
