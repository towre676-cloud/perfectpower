# Exact geometry statements on numerical surface models

This release adds two concrete capabilities to the analytic geometry layer: conservative Voronoi boundary enclosures for the explicitly represented rational polyhedral metric, and an integral symplectic homology basis on a closed oriented triangulation. It does not claim to solve certified smooth arbitrary-genus Voronoi boundaries or general analytic period integration. The distinction is mathematical: exact statements about a specified finite surface model can coexist with an uncertified approximation of a smooth curve.

## Voronoi enclosure theorem

Interpret each decimal edge length as an exact rational number. For a triangle with vertices a,b,c, let G=[[A,C],[C,B]], where A=length(ab)^2, B=length(ac)^2 and C=(A+B-length(bc)^2)/2. Positive determinant is checked using rational arithmetic. Thus each triangle has a genuine Euclidean metric with those lengths, and compatible edge lengths glue to a continuous polyhedral length metric.

A continuous piecewise affine scalar function f is globally 1-Lipschitz if its gradient norm in every triangle is at most one. With u=f(b)-f(a) and v=f(c)-f(a), its squared gradient norm is exactly (B u²-2 C uv+A v²)/(AB-C²). The implementation converts proposed heat fields to rational vertex values, checks every triangle, and divides each field by a rational upper bound for its maximum gradient norm. The proposals can be numerically inaccurate without invalidating this bound.

Consequently L_s(p)=max_f |f(p)-f(s)| is a lower bound for intrinsic distance from p to site s. An edge path from s to a triangle vertex followed by a straight segment inside that triangle gives an upper bound U_s(p). Dijkstra is used only to select these explicit upper-bound paths; graph distance is never identified with intrinsic geodesic distance. Square roots are rounded outward using integer square root arithmetic, without floating predicates.

For a triangular patch centered at p, a rational upper bound r for the distances to its three corners also bounds the distance to every point in the patch, by convexity of the norm. If U_s(p)+2r < L_t(p) for every competing site t, the entire patch belongs strictly to site s. Otherwise the patch is subdivided into four midpoint triangles until the selected finite depth. Unresolved triangles form a conservative enclosure of every true Voronoi boundary of the specified polyhedral metric. Large unresolved regions are legitimate results; no boundary accuracy or shrinkage rate is promised. Equal-distance ties remain unresolved. Every face is partitioned exactly, with rational area fractions adding to one.

The existing curve meshes obtain edge lengths from numerical quadrature. Reading their decimal lengths as exact rationals establishes a well-defined nearby metric, not a rigorous approximation bound to the smooth conformal metric. Transferring the enclosure to that smooth metric requires independently proved comparison bounds, ideally local tensor bounds with rigorous branch and infinity chart integration. This release provides no such comparison and labels all outputs accordingly. It also provides executable exact arithmetic checks rather than Lean theorems.

## Integral homology and symplectic reduction

A connected closed oriented triangulation is checked through opposing halfedges and connected circular vertex links. Choose a primal spanning tree T and a dual spanning tree T* among edges outside T. The remaining edges number 2g. Gluing triangles across T* produces a disk; walking its boundary and contracting T produces a polygon word with each remaining edge appearing twice with opposite signs. This is the standard tree/cotree construction; see Jeff Erickson's [surface-map notes](https://jeffe.cs.illinois.edu/teaching/comptop/2020/notes/19-surface-maps.html) and [homology basis notes](https://jeffe.cs.illinois.edu/teaching/comptop/2023/notes/22a-homology.html).

The basis generators recorded here are dual loops, not the primal polygon edges. Each loop travels in T* from the base face to the right face of its oriented handle edge, crosses that edge to its left face, and returns through T*. In the polygon these loops are oriented chords between the paired boundary occurrences. Alternating endpoints determine their signed intersections. The resulting integer alternating matrix Omega is reduced over the integers.

At each reduction step a vector a is paired with an integer vector b satisfying Omega(a,b)=1. Smith operation transcripts establish the existence of b and give a saturated integer basis for the orthogonal complement. Repeating this process constructs an integer matrix S with integer inverse and S-transpose Omega S = J, where J=[[0,I],[-I,0]]. The generated receipts retain the polygon word, explicit based dual walks, original intersection matrix, basis transform, inverse, and replayable Smith transcripts. A nonunit pivot is rejected rather than silently using a rational basis.

The implementation takes an oriented triangulated surface as input and has no fixed genus cap. Replayed curve examples cover genera one, two and three in tests, with generated receipts for the existing genus-two and genus-three meshes. Generic combinatorial code does not mean the current hyperelliptic mesh builder handles every algebraic curve. Neither numerical root finding nor the identification of that mesh with the intended smooth algebraic surface has become certified by these integer computations.

## Period matrix interface and the remaining integration step

Given a g by 2g array P of integrals of the same ordered holomorphic forms over the recorded dual generators, the transformed array PS has A and B blocks. The normalized matrix is tau=A-inverse B. The interface reports symmetry residual and eigenvalues of the symmetrized imaginary part. These are numerical diagnostics. Supplying arbitrary numbers that pass them does not prove those numbers are periods.

The subsequent analytic push now integrates forms along these dual walks for the supported squarefree hyperelliptic curve meshes; see [the symplectic analytic monograph](SYMPLECTIC_ANALYTIC_MONOGRAPH.md). The paragraph below records the requirements and limits of that connection. The earlier continued-sheet contour integrator computes genuine closed contour integrals, and the new analytic cycle module connects the mesh homology basis to finite and inverse chart segment integration. That connection needs consistent face charts, interior representatives of edge crossings, continued sheets along the full dual walks, complex-compatible orientation, and independent Riemann bilinear checks. Rigorous quadrature then needs outward analytic error bounds. The numerical hyperelliptic connection is now implemented, including sheet and bilinear checks. Certified analytic error bounds and symplectic integration for higher cyclic powers remain unfinished.

## Reproduction

Run `PYTHONPATH=python python python/build_certified_surface.py` to regenerate the topology and boundary-enclosure receipts from the previous analytic mesh corpus. Run `PYTHONPATH=python python -m unittest discover -s python/tests` for the full Python suite. The CLI commands `surface-homology --coeff=0,-1,0,0,0,1 --resolution 6` and `certified-voronoi --coeff=0,-1,0,0,0,1 --resolution 6 --sites 4 --depth 2` expose the new capabilities through the existing main module. NumPy and SciPy remain optional dependencies needed for curve mesh generation and heat-field proposals; the rational bound engine and integer homology routines use the standard library.
