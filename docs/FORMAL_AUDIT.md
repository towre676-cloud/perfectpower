# Formal boundary and audit

The original ZIP contained `Basic.lean`, `Density.lean`, `Rigid.lean`, `Estimates.lean`, `Dichotomy.lean`, the module umbrella, a Lean v4.20.0 toolchain, a Mathlib dependency at `master`, and a README claiming no `sorry` while explicitly admitting the files had not compiled. The repository now pins the named Mathlib tag `v4.20.0`; this tag and APIs have not been checked from the current environment because the GitHub/release endpoint was unreachable. All theorem declarations remain **attempted Lean code**. Do not cite the tree as a formal proof. The Python tests do not elaborate Lean code.

`Basic.lean` states an integer-root hit predicate, Finset count, ordinary convergence predicate, and limsup upper density. Its bridge uses `h.limsup_eq`, an API call requiring an actual Mathlib build to validate. `Density.lean` attempts the bounded-count squeeze, a fixed integer count difference for two separately bound sequences, a bounded-limsup perturbation lemma, and a periodic count decomposition. These are mathematically sound target statements. Their tactic syntax, lemma names, coercions, and `limsup` side conditions remain unchecked. `Rigid.lean` attempts rational-denominator clearing, a Gauss-content integral-closure step, and a recursive truncated root. `Estimates.lean` attempts real asymptotic and integer-root separation. Its proof route should be compared against the explicit numerical certificate in Python, especially nonvanishing of the remainder. `Dichotomy.lean` assembles the rigid disjunction. None of these files states or proves the nonrigid Boshernitzan branch, so even successful compilation of the existing tree would establish at most the rigid branch.

The corrected mathematical interface requires d≥2 at its public theorem boundary. The Lean predicate currently accepts all natural d and relies on callers to supply d≥2 where needed. A future refactor can use a structure carrying the lower bound, while preserving generic internal lemmas where harmless. The finite-surgery theorem now binds `{S S' : ℕ → ℤ}` separately; this fixes the shadowed binder from the older version criticized by the user. The exact D uses the prefix through N₀−1. A rigorous limsup comparison needs explicit boundedness side conditions, supplied by 0≤A(N)/N≤1. The periodic theorem should ideally first be stated for a periodic 0/1 indicator and then specialized to hits.

The older τ-monotonicity claim, Float-based manifest order proof, Čech obstruction declaration, tropical maximum, and BSD conjecture do not occur in this attached source tree. Their prior critique is integrated into `MONOGRAPH.md`. No corresponding Lean files or stale receipts were invented or silently relabeled in this repository. The next Lean milestone is a CI run with a real Mathlib pin, with every theorem elaborated, all dependencies fetched from an authorized endpoint, and a recorded build log. If compilation fails, retain the log and repair statements before marking any receipt proved.
