# Integral output machines

PerfectPower can now compress supplied integer operator models without introducing fractional state transitions or fractional readouts. It keeps the same minimal dimension established by the existing rational Hankel certificate, and retains exact integer-image restrictions on finite witness observations. Repeated outputs can be evaluated modulo any composite or prime-power modulus, including primes dividing denominators in the earlier rational coordinates.

## Older source and the extension made here

This work revisits three original Wilson Forge theorem files: [Integral Sparse Native ISA v0.21](../galois_merge/vendor/forge/THEOREMS/INTEGRAL_SPARSE_NATIVE_ISA_v21.md), [Task Adapted Section Synthesis v0.20](../galois_merge/vendor/forge/THEOREMS/TASK_ADAPTED_SECTION_SYNTHESIS_v20.md), and [Dual Hankel Execution Semantics v0.26](../galois_merge/vendor/forge/THEOREMS/DUAL_HANKEL_EXECUTION_SEMANTICS_v26.md). The source review records their hashes and the exact adaptation boundary.

V0.21 supplies an integral instruction language and explicitly leaves the integer/rational word-section problem open. V0.20 insists that an image's actual position matters beyond its rank. V0.26 separates written algebra order from chronological column execution. We combine these ideas with the repository's existing rational machine certificates and unimodular Smith transcripts to construct integer output coordinates and divisibility-sensitive observation fibres.

This extension does not solve the original 638-dimensional synchronized word-section optimization, minimize coefficient height, prove a smaller primitive-call count, or identify the full Z-module generated by all orbit words. The construction is classical rational linear representation and saturated lattice arithmetic applied to the stored models. Background: Kiefer's [weighted-automata notes](https://arxiv.org/abs/2009.01217) and SageMath's [integer-matrix saturation and Smith documentation](https://doc.sagemath.org/html/en/reference/matrices/sage/matrix/matrix_integer_dense.html).

## Why rational compression leaves an arithmetic gap

The existing minimal machine uses actual reachable word vectors as a rational basis. Independent integer vectors need not form a primitive integer lattice basis. For example, seed (0,2) and operator [[1,1],[0,1]] produce a two-vector basis with index four in Z². Rational coordinate changes can divide by that index. Treating every compressed rational coordinate as an arbitrary integer, or reducing a fractional transition at a denominator prime, changes the arithmetic problem.

There are two different lattices. The Z-span of a selected finite word basis is a finite-index sublattice of its saturation. The saturation is the set of all integer states in the same rational reachable space. It is preserved by every integer operator that preserves that rational space. It need not equal the Z-span of all orbit words. The new machine uses the saturation and retains the fixed seed exactly.

## First Smith chart: saturated reachable states

Let J contain the independent word states from the checked rational certificate, of rank r in an n-dimensional ambient state space. A unimodular Smith transcript supplies

\[
UJV=\operatorname{diag}(d_1,\ldots,d_r,0),\qquad d_i>0.
\]

The first r columns of U⁻¹ give an integer saturation basis R. The first r rows of U give its coordinate map P, with PR=I. The selected word basis has index ∏d_i in this saturation. This is a selected-basis index, not an invariant of the complete orbit module.

Every source operator A_i preserves the rational reachable span and maps integers to integers, so A_i R=R B_i with integer B_i=P A_i R. The seed has exact integer coordinates t₀=P s and R t₀=s. These are finite identities checked in the receipt.

## Second Smith chart: invisible states and the quotient

The rational machine records k independent future observation rows, each with an actual readout and chronological execution word. Evaluate those same words on R to form the integer matrix O of size k×r. Its rational kernel is exactly the state directions invisible to every future supplied readout.

A second transcript gives U_o O V_o in Smith form. Because a kernel of an integer map to a free abelian group is saturated, its quotient is free. Define Q as the first k rows of V_o⁻¹, C as the first k columns of V_o, and K as the remaining columns. Then

\[
QC=I_k,\qquad QK=0,\qquad \ker_{\mathbf Z} O=K\mathbf Z^{r-k}.
\]

The compressed integer operators and readouts are

\[
D_i=Q B_i C,\qquad H_{\mathrm{min}}=HRC,\qquad q_0=Qt_0.
\]

The checker verifies the descent identities QB_i=D_i Q and HR=H_min Q. Thus every finite source word on the fixed seed has exactly the same output in the compressed integer machine. The rational certificate's nonsingular Hankel minor supplies the lower bound k; an integer k-dimensional realization supplies the upper bound. Any smaller integer realization would also be a smaller rational one. The new realization therefore has the same minimum state dimension, without a claim of minimum coefficient height or execution cost.

The two Smith reductions and their unimodular operation transcripts are included. Replay checks them and the displayed identities without discovering a new reachable basis, Smith reduction or matrix inverse. All source, transition, readout and seed entries in the integer realization are integers. JSON rational strings representing integers are accepted; floats, booleans and nonintegral source coefficients are rejected.

## Exact observation fibres, with the missing congruences retained

Suppose a caller proposes values b for the certificate's k finite witness observations. The complete integer condition is O t=b for t∈Z^r. Rational solvability is automatic here because O has full row rank, but integer solvability can fail. The second Smith transcript checks the transformed divisibility conditions exactly. If one fails, the result contains a row annihilator, modulus and nonzero residue. If they all hold, it gives one integer state and a complete integer basis for every invisible direction.

Mapping this fibre through R gives every original integer state in the saturated reachable space with those observations. Its quotient coordinate is unique. This does not decide whether the state occurs on the original seed orbit. The word witnesses label these observations; they are not assumed to be an arbitrary consecutive sample list.

The recorded image factors describe this selected finite observation map O. Replacing the chosen observations can change those factors. They are not advertised as canonical invariants of the Z-module generated by every future observation row.

For operator [[1,1],[0,1]], seed (0,2), and readout (4,0), the selected observations are 4x and 4(x+y). The image factors are [4,4]. Proposed values (2,0) are rationally possible but impossible for integer states; a modulus-four obstruction proves this. Values (4,12) lift to state (1,2). The saturation permits (1,2), while the original seed orbit has both coordinates even. Keeping those two scopes separate is essential.

`project_state` rejects states outside the saturated reachable space. `distinguish_states` compares the quotient coordinates: equality means every future supplied readout agrees, and inequality returns a concrete readout word whose exact output difference separates the states. It does not claim the returned word is the globally shortest separator.

## Composite-modulus evaluation without rational inverses

`modular_power_output` uses the compressed integer matrices directly, reducing after each binary product. It computes H_min D_i^n q₀ modulo any m≥2 within the 64-bit input budget. No inverse of a rational-coordinate denominator is needed. This supports modulus two, four, six, eight, nine and twelve directly, including the denominator primes of the previous models. It returns the exact output residue for the fixed supplied seed; it does not infer a complete period or classify every perfect-power index.

`integral_power_output` computes exact integer values with a rational bit guard on each product; `integral_word_output` accepts general operator words. Both preserve the chronological column-vector convention, and general words may explicitly request written order by reversal. Zero seeds, entirely invisible outputs and zero-dimensional quotients are handled explicitly.

## Usage

```sh
python -m perfectpower integral-machine \
  --operators '[[[1,1],[0,1]]]' --seed '[0,2]' \
  --readouts '[[4,0]]' --word '[0,0]' --observations '[2,0]' --verify

PYTHONPATH=python python python/develop_integral_machines.py
```

The API also accepts a checked rational receipt through `integralize_machine`. Interfaces are in [integral_machine.py](../python/perfectpower/integral_machine.py). Smith operation, entry-bit, closure-product, input-shape, word-length and repeated-index budgets fail explicitly; no partial machine is returned as complete.

```python
from perfectpower.integral_machine import integral_machine, modular_power_output

machine = integral_machine([[[2]]], [1], [[1]])
print(modular_power_output(machine, 10**12, 12))  # (4,)
```

## Stored workload and proof boundary

The 135 stored recurrence models form 40 shared-machine groups. Their 368 separate state coordinates still reduce to 121, now with integer transitions, readouts and initial coordinates. The older rational versions had 37 fractional transition entries and 23 fractional readout entries; the new versions have none. This preserves the earlier compression and does not claim a further state-count reduction. Their original OEIS definitions remain a separate identification question.

The runner independently compares exact outputs to the existing recurrence executor and also checks composite-modulus outputs. Tests compare all short words of random multigenerator models to direct source-matrix iteration, replay serialized receipts without discovery, retain future-visible directions, exercise nonprimitive bases and prime-power observation obstructions, and reject altered identities and Smith transcripts. Deterministic certificates and validation logs live in [receipts/integral_machines](../receipts/integral_machines).

The retained corpus has 810 independent exact-value comparisons and 4,320 modular comparisons across moduli 2,3,4,6,8,9,12,19. Twenty-seven selected reachable word bases are nonprimitive; the largest selected-basis index is 8,957,643,552. Ten selected finite observation maps have nontrivial image factors. These are workload facts about the explicit recorded bases and observation maps, with the scope distinctions above.

The complete Python test discovery runs 710 tests: 706 pass and four are skipped. All 17 new focused tests pass again from an extracted archive under `python -S` outside the checkout. The fresh-copy runner reproduces all three deterministic receipt files byte for byte. [Validation metadata](../receipts/integral_machines/validation.json) records source hashes and the archive tree; the new integer implementation's formal status remains separate from the earlier recorded Lean checks.

This development adds Python algorithms and exact replay certificates; it performs zero new Lean compilations.
