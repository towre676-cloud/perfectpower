# PerfectPower: accumulated branch integration

This release brings the completed BLAST and model-counting lanes into the current geometry work on main. The inventory found nine published side branches. Six were already ancestors of main; the three outstanding tips were the BLAST mining branch and the two nested model-counting releases. The later counting release includes the earlier release, so its history preserves both. The complete local integration also incorporates the recovered structural-counting and BLAST completion commits, including the source inputs omitted from the earlier GitHub upload. The branch inventory and exact source identities are retained in `receipts/branch_integration/integration.json`.

The complete archive and the public GitHub tree have a documented difference. Automatic approval review rejected publication of new detailed counting comparisons and opaque biological data carriers. Those files remain in the complete archive. The public integration retains the software, mathematics, already published evidence, source acquisition routes, and proof sources. It does not claim that every locally completed dataset or new performance result has been published. The older BLAST publication receipt remains a historical record of its earlier attempt.

The merge preserves original coordinates throughout. A CNF formula over a declared variable universe has a finite population of satisfying assignments. A variable absent from all remaining clauses still contributes its two possible values. A forced variable contributes a unique extension. Independent components contribute a product of their counts, while the two branches of a decision contribute a sum. These facts support conditional counting, lexicographic selection, reverse ranking and uniform samples. The native engine uses exact integers and full normalized cache keys. A timeout remains an unfinished query rather than an estimated exact answer.

The recovered structural engine recognizes complete definitions of signed gate outputs and performs bounded resolution on those outputs. Its counting justification is a bijection: restricting a satisfying assignment removes a uniquely determined coordinate, and every residual assignment has exactly one extension through that gate definition. Ordinary satisfiability-preserving projection does not have this guarantee. The sparse elimination planner instead represents the count as a sum of products of clause indicators. Eliminating a variable sums its two values in the factors containing that variable. The neighbor scope determines the size of the next exact table. Heuristic planning and explicit work limits choose where this operation is practical; they do not make arbitrary counting polynomial-time.

BLAST consumes the same exact counting machinery as a dependency while retaining its own sequence and annotation semantics. Tracebacks are replayed against supplied sequence coordinates. Compatible HSPs form finite directed path populations; coverage and path length contribute the exponents of the associated generating polynomial. The recurrence is linked to the finite path language in Lean, and decreasing ranks establish the retained completeness argument. Generic raw traceback acceptance and the retained literal source examples are separate formal obligations. The merge keeps those proof sources alongside the geometric sources rather than replacing either library.

The geometry lane remains available through the unified command dispatcher. Its polynomial chart compiler retains rational metric coefficients, excluded loci and continuous-domain bounds. Its dynamics include conformal connection coefficients, geodesic acceleration, Hamiltonian quantities and parallel transport. Continuous length comparisons refer to specified path domains. Numerical trajectories remain exploratory, and general compact higher-genus distance questions are not closed by this integration. The existing monographs state the precise scope of each construction.

Shared build files now expose the geometry, BLAST and counting reproduction targets together. The package keeps the optional differential compiler dependency while adopting the structural counting version. The installed runtime carries the actual native counter source and original-coordinate fixtures. An additional installed-wheel check exercises exact counting, conditioning and rank/selection alongside the existing algebra, observational-equivalence and differential-geometry routes. The installer therefore checks the combined runtime rather than merely importing each newly merged module.

Focused integration checks passed for 63 BLAST tests, 24 counting tests and 95 geometry tests. Fresh Lean checking accepted 17 BLAST modules. The native sanitizer checked 1,000 exhaustive small formulas, 80 exhaustive gate-circuit inputs and two analytic paths. The installed wheel passed its retained public-route checks. Repository integrity checks found no broken links or data-hash mismatches before the public projection. The broader historical suite was interrupted during its unchanged 457-curve Mordell audit. Its initial dependency errors were followed by installation of the declared optional dependencies and a successful 59-test rerun, with 11 optional skips. This targeted integration does not claim a complete historical Python or Lean build or a new replay of every old benchmark.

The complete archive retains the original research monographs, exact source datasets and detailed result files as well as this integration account. The public source tree documents the withheld files so a reader can distinguish an available executable route from a dataset that must be acquired or supplied. Public-checkout CI runs the synthetic software checks and checks the retained Lean literal sources with an explicit proofs-only mode. That mode records that original raw-source correspondence was not rechecked. Full raw-source checks retain their original stricter default and run when the complete datasets are supplied. Branch heads are preserved in the integration history and inventory. This release consolidates the work without converting historical measurements into new measurements or enlarging their scientific scope.
