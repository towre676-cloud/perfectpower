# Completed BLAST work: combined release

This release collects the previously local certification commit `6420957` and the separately uncommitted OXBench experiment into one BLAST checkout. It preserves the entire mining extension at `367147e`, adds the complete INS-query corpus experiment, and adds the externally annotated structural-domain benchmark. The dedicated publication destination is `towre676-cloud/perfectpower`, branch `codex/blast-mining-machinery-20261011`. Local completion and remote publication are separate states; see `receipts/blast/finish/publication.json` for the observed publication outcome.

## What is complete

The retained INS-query database contains 930 accession-version records. Three insulin-family queries define 2,790 query/database pairs. The native exhaustive affine reference scores every pair on both subject strands. The three retained BLAST word-size experiments contain 162,253 HSPs in total, all covered by executable source replay and independent adapter checks. The retained original XML supplies 931 annotated source records, including the external mouse query, and preserves the feature qualifiers. The standard-code CDS audit accepts 914 translations and retains 17 explicitly unresolved ambiguity/exception cases.

The generic Lean recurrence theorem connects suffix-polynomial coefficients to an explicit finite path language. Rank bounds establish completeness for sufficient fuel, and distinct successor lists establish absence of duplicated vertex paths. The generic BTOP soundness theorem connects successful raw traceback decoding to declarative trace validity and coordinate bounds. Sixteen source modules include the generic results, literal source carrier, and all 624 word-size-28 HSP certificates. A separate OXBench module checks 24 literal protein tracebacks and two rejection examples. These are acceptance results for supplied finite inputs; they do not prove arbitrary Python executions or the correctness of HTTP, XML, FASTA, tar, or hash implementations.

OXBench contributes all 395 declared structural-domain reference sets, 3,292 sequence occurrences and 978 distinct sequence strings. Each search uses the complete pooled carrier of 10,837,264 ordered occurrence pairs. The biological retrieval denominator consists of all 101,750 within-set directed nonself pairs. Both standard BLASTP and BLASTP-fast outputs are retained and executable-replayed, including cross-set and self HSPs. Conserved uppercase reference positions determine the independent residue comparison. Labels never enter the BLAST search, chain construction, chain selection, or coverage threshold.

At half-query coverage, standard BLASTP single-HSP retrieval accepts 73,003 positive directed pairs. Ordinary coherent chaining and exact-population chaining each accept 73,006. Interval union accepts 73,021, including 15 acceptances that fail the coherent monotone-chain rule. Thus the empirical gain over single HSPs is three directed pairs; there is no recall gain over the appropriate ordinary chaining baseline. Complete population counting costs more on this mainly single-HSP corpus. All measurements, negatives and explicit work-limit states remain in the receipts. Structural-domain membership is not an orthology/paralogy label, and no biological discovery or whole-NCBI nt/nr recall claim follows.

## Reproduction

Use Python 3.11 or later and run `make blast-oxbench-test`, `make blast-oxbench-replay`, and `PYTHONPATH=python python scripts/check_blast_oxbench.py` for the protein work. Run `make blast-certification-test` and `make blast-certification` for the nucleotide corpus. The last command requires a C++17 compiler for the independent exhaustive score reference. Reproduction uses retained bytes and does not refresh the database. `--run-blast` is a separately requested local executable regeneration, and the fetch scripts are separately requested network acquisitions.

With Lean 4.20.0, run `python scripts/check_blast_certification.py --lean lean --jobs 2` and `python scripts/check_oxbench_kernel.py --lean lean`. These checks compile the relevant finite source modules independently of unrelated research modules. On normal installations no special runtime wrapper is needed. CI configurations run the source replay and targeted kernel routes separately. A configured CI job is not evidence that GitHub hosted runners actually executed it; retained local logs provide the completed evidence here.

The package includes source, raw retained inputs, complete evaluation receipts, generated Lean sources, the offline explorers, both detailed monographs, and this completion note. Extract every numbered ZIP into the same parent directory. Their common `perfectpower/` tree reconstructs the complete source snapshot; `PACKAGE_MANIFEST.json` provides SHA-256 values for each retained file. No binary Lean toolchain or build cache is included. A Git bundle preserves the local BLAST commit history so the pending publication can be completed without reconstructing source changes.

## Remaining research boundaries

A general implementation refinement for the Python graph builder, polynomial updates and source parsers remains open. The word-size-7 and word-size-11 nucleotide outputs and the complete protein outputs are executable-audited; only the explicitly generated literal sources are kernel-checked. The source annotations are accepted external references, not proved biological truth. Full orthology/paralogy evaluation requires an independently annotated gene-tree benchmark. Recall over another database requires a newly pinned carrier and new denominator. Closing the half-committed release does not silently close these mathematical or scientific research questions.
